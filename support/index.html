How can we help?

Open a support issue on GitHub. Issues are public: never include passwords, authorization tokens, sign-in codes, private prompts, or account screenshots containing personal information.

Connect your account

Tap Connect Codex, open OpenAI’s sign-in page and enter the code shown in the app. If requested, enable device-code login in ChatGPT security settings. Return to Token Widget after signing in. Your account must be eligible for Codex.

Usage looks out of date

Open the app and refresh usage. Widgets show the most recently synced data and refresh when iOS allows. Missing token statistics mean the account has not reported that information. This is not a complete meter for all ChatGPT messages.

Create a companion

Open Pet, then Create with Codex. Describe a creature, generate it, preview it and choose Keep this companion. This uses your Codex allowance or credits. Ten attempts per session are allowed per rolling 24 hours. Cancellation and failed attempts can consume allowance. Resume checks the existing request instead of starting another.

Disconnect and delete service data

Open Account and choose Disconnect account. The app deletes the connection service’s stored authorization, account details, cached usage and generation results for that connection. If offline, syncing stops and the app shows Retry disconnect until server cleanup succeeds. Local companion data can remain on the device. Disconnect other devices separately. Your OpenAI account is not deleted.

Why is a reset only displayed?

Token Widget displays reset availability reported by Codex. Redeem resets and manage credits in Codex; this app does not perform those actions.
